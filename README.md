**All the Mods 9: Expert** is a rebuilt, __GregTech-driven__ take on ATM9. Forget the usual ATM approach of progressing through each mod on its own. Here, you actually have to use all the mods to advance.

**What actually changed**  
Pretty much every recipe has been reworked or replaced. __Everything has been _Gregified___: magic, tech and exploration all run through GregTech.  
Want to make a Mystical Agriculture seed? **Too bad**, time to build a Seed Fabricator.  
Need hafnium for Mekanism? It’s on the Moon. Getting there means building a rocket, which has its own processing chain.  
Magic mods no longer standalone. Their machines, rituals and materials plug into GregTech multiblocks and processing lines.

**Leaner, more focused mod list**  
Mods that weren’t pulling their weight have been cut, and new ones have been added, including Forestry, Gendustry, Elemental Craft and ProjectE, among many more.


All the Mods started out as a private pack for just a few friends of mine that turned into something others wanted to play! It has all the basics that most other "big name" packs include but with a nice mix of some of newer or lesser-known mods as well. 

Does "All the Mods" really contain ALL THE MODS? No, of course not.
